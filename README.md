## How to protect against packet sniffing:

- Preventing a packet from being sniffed is impossible because it passively and silently copies all the data that goes through it, so the best way to protect against it is to use strong encryption so that any data intercepted becomes unreadable. Solutions therefore include the use of HTTPS over HTTP to protect the data and VPNs to hide other information like the packet's route and destination.
